# wheatbit.github.io

The simpler sister page of Methodical Enterprises LLC, served by GitHub Pages from this repository
at <https://wheatbit.github.io>. The main site, <https://methodical-ep.com>, is served by
Cloudflare Pages from [WheatBit/methodical-ep-site](https://github.com/WheatBit/methodical-ep-site).

- `index.html` is the whole page: the company and its apps, with each app's platforms, its own
  website where it has one, its store links and its privacy policy. Keep the app list in step with
  methodical-ep.com: when an app's store status changes, update both pages.
  It loads nothing from other sites (no fonts, scripts or trackers).
- The privacy policies live in [WheatBit/AppPrivacy](https://github.com/WheatBit/AppPrivacy) and
  appear under `/AppPrivacy/` on the same domain.
- `logo.png`, `apple-touch-icon.png` and `favicon.png` are the company logo at 256, 180 and 64 px.

Nothing sensitive belongs here: this repository is public.
